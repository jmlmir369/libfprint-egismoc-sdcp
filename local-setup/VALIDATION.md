- 이 세션에서 설치한 빌드의 SHA-256: `11c49fe6440d6a737495180cd3e7b2bef52c08e502d1c6727261a847b6a5fe33`.
- 사용자 지문 데이터와 개인 시스템 로그는 저장소에 포함하지 않았습니다.

## 자동 검사

- 기존 유닛 시험 3묶음 및 신규 보안 회귀시험 1묶음 통과.
- 암호 시험 6개와 보안 회귀시험 6개를 ASan/UBSan으로 통과. 실행환경 제약으로 별도 누수 검사는 제외.
- 보안 회귀시험: 정상·변조 서명, 정확한 바이너리 접두부, 잘린 패킷, 새 키에서 과거 인증 MAC 거부, 공개 Egis 통신의 인증서·두 서명 검증, 새 연결 실패 후 재시도와 이전 키 폐기.
- 실행 프로그램과 라이브러리의 동적 연결 검사 통과.
- 이미지 조립 시험은 관련 개발 구성요소가 없어 제외.

## 실제 장치 검사

| 확인 항목 | 결과와 근거 |
|---|---|
| 오른손 엄지 등록 | 10단계 등록 완료 |
| 등록 지문 인증 | 일치 성공 |
| 지문 서비스 재시작 후 유지 | 다시 일치 성공 |
| 비밀번호 대체 경로 | 지문 없이 기다리면 기존 비밀번호 입력 단계에 도달함. 암호 입력은 수집하지 않음 |
| 기존 비밀번호 설정 | 원본 인증 설정이 지문 모듈 다음에 그대로 보존됨을 대조 |
| 실제 잠금 해제 | 잠금·해제를 감지했고, 사용자가 오른손 엄지만으로 해제됐음을 확인 |
| 미등록 손가락 | 두 번째 잠금 시험에서 사용자가 거부를 확인한 뒤 등록 엄지로 해제 |

엄지 위치에 따라 일부 시도에서 불일치가 나왔고 재시도로 일치했습니다. 이 관찰로 장기간 인식률이나 오인식률을 추정하지 않습니다. 초기 무응답 시도 뒤에는 준비 상태를 표시한 창을 사용해 일치를 확인했으며, 무응답 원인을 전원 절약으로 단정하지 않았습니다.

## 설치 및 보관

라이브러리는 `/usr/local/lib/fprint-egismoc-sdcp`에 두고 지문 서비스에만 지정했습니다. 화면 잠금은 지문 우선, 기존 비밀번호 대체 경로를 유지합니다. 원본 설정 백업과 `rollback.sh`를 같은 설치 디렉터리에 보관합니다. 임시 진단 설정은 제거했습니다.

소스의 원격 보관과 트리 일치를 확인한 뒤 로컬 개발 소스·빌드·패치·업로드용 사본을 삭제했습니다.

## 남은 한계

전체 보안감사, 통계적인 오인식률 평가, 전체 USB 비동기 경로 검증은 아닙니다. 절전·재부팅 후 및 장기간 동작은 별도 확인이 필요합니다. 공식 제안과 동일하게 장기 사용 센서의 모델 인증서 날짜 검사는 생략하며 신뢰 체인과 서명은 검사합니다. 펌웨어 해시의 허용·폐기 정책이나 Windows Hello 전체 보안 체계까지 구현하지 않습니다.
